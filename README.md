# scripts

A personal collection of scripts across languages, organized by folder.

## Structure

- [`bash/`](./bash/README.md) — Bash scripts
- [`python/`](./python/README.md) — Python scripts
- [`php/`](./php/README.md) — PHP scripts
- [`javascript/`](./javascript/README.md) — JavaScript scripts

Each language folder has its own README indexing what's inside.

## Usage

Clone the repo and run scripts directly from their folders. Each script includes usage instructions in its header comment or a companion README.

```bash
git clone https://github.com/mavhezha/scripts.git
cd scripts
```
